# Dryline — Live Demo Script

**Slot:** ~3 minutes (within a 5-minute pitch)
**Demo trio:** Wimberley → Taylor → Fort Stockton
**Format:** Beat-sheet, with verbatim language for the hero lines.

> Live tool calls so the reasoning trace is real. Demo addresses are pre-staged so the responses land cleanly within the time budget.

> **Verbatim** lines are in quotes — say these as written. **Beat** descriptions are stage directions and adlib-friendly framing.

---

## Pre-flight checklist

Before you walk on stage:

- [ ] Browser zoomed to ~110% so judges can read result cards from the back of the room.
- [ ] DevTools closed. Mode toggle defaulted to **Personal**.
- [ ] Three demo-address buttons visible above the search bar: **Wimberley · Taylor · Fort Stockton**.
- [ ] MCP server warm (one throwaway investigation already cached in the last 5 minutes).
- [ ] Map centered on Texas at state-level zoom.
- [ ] Speaker notes window on second monitor; main monitor mirrored to the projector.

## Demo 1 — Wimberley, TX (~50 seconds)

**Mode:** Personal · *Will the water last here?*
**Why first:** Warm-up. Judges know it (or have been there). Relatable. Gets the audience nodding before we ask them to think hard.

| # | On screen | Spoken |
|---|---|---|
| 1.1 | Click the **Wimberley** demo button. Map flies to a parcel pin in the Hill Country. | "Let's start with a Hill Country address — a weekend home in Wimberley." |
| 1.2 | Reasoning trace begins streaming on the right rail: *"Resolving location… Identifying watershed… Hays Trinity GCD…"* | **Verbatim:** *"You can see the agent working in the side rail. It's resolving the location, identifying the watershed, and figuring out which Groundwater Conservation District has jurisdiction."* |
| 1.3 | Result cards populate: **Drinking Water · Drought · Reservoirs · Aquifer · Rivers**. The Aquifer card animates in with a 20-year time series sloping down. | "Wimberley sits on the Trinity Aquifer. About half the homes here are on private wells. You can see the long decline." |
| 1.4 | Drought card shows current stage and what it forbids. | "We're in drought stage 4 right now. The card shows the watering rules — no surface watering between 10 and 7." |
| 1.5 | Synthesized summary appears with inline citations. Hover one to show the source URL + retrieval timestamp. | "The summary cites every claim. Hover any sentence — it links back to the source with a timestamp." |
| 1.6 | Click the **Actions** tab. A draft *"Should I deepen my well?"* artifact slides in with a cost-estimate range based on Hays County driller depth records. | "And the agent drafts a concrete next step — should I deepen my well? Here's the depth-cost band based on local driller data." |

**Time check:** Should hit ~0:50 here. Move to Taylor.

## Demo 3 — Fort Stockton, TX (~50 seconds) · The closer

**Mode:** Transparency · *Comanche Springs.*
**Why last:** Historical weight. The cautionary tale of Texas water. A graph that drops jaws.

| # | On screen | Spoken |
|---|---|---|

| 3.2 | The Aquifer card and a custom **Historical Springs** card resolve together. Powered an entire irrigation society. In the 1950s, irrigation pumping from the Edwards-Trinity aquifer dried them up — and the 1954 Belding case made that legal under Texas's rule-of-capture doctrine."* |
| 3.3 | Pause. Let the flatline graph sit on screen. | *(silence — count 1-Mississippi-2-Mississippi)* |

## Hero lines, isolated

If you forget everything else, land these four:

1. **Slide 1, opening:** *"A dryline is the boundary across Texas where moist Gulf air meets dry continental air. It's where Texas weather and Texas water meet, every day."*
2. **Demo 2, the tension:** *"It cross-referenced two things on its own — the aquifer is in decline, AND a 4.2 million-gallon-per-day permit was filed nearby in March. No human told it to put those side by side."*
3. **Demo 2, the hand-off:** *"This is the moment Dryline stops being a tool and starts being an agent. Public data went in. A fileable civic action came out."*
4. **Demo 3, the modern echo:** *"Same aquifer. Same doctrine. Seventy years later."*

## Live demo failure modes — and what to say

| If… | Do this | Say this |
|---|---|---|
| MCP tool times out on a card | Don't apologize. Click the next demo button. | "Live tool call, gauges API can be slow. Moving on — the investigation is the point." |
| Map fails to load tiles | Switch to a screenshot fallback (in `/fixtures/screenshots/`). | "Map tiles being slow. The data we care about is in the side rail." |
| Reasoning trace stalls | Wait two seconds. If still stalled, click into Actions tab and present the drafted artifact. | "While the agent finishes, here's what it produced last time we ran this address." |
| Address resolves to wrong place | Use the demo button instead of typing. | "Demo button is the safe path." |
| Audio/projector dies | Pick up at slide 9 verbally; describe one drafted artifact from memory. | "Briefly without slides — Dryline ships an MCP server, an agent skill, and a map app. Every claim cites a source. Every investigation drafts a civic action." |

## Live-demo discipline

- **Don't read the screen aloud.** Judges can read. Talk over the screen, not from it.
- **Don't say "and as you can see…"** every five seconds.
- **Pause on the flatline.** A full second of silence is more memorable than another sentence.
- **Don't apologize for caveats.** The caveats card is a *feature*. Point at it once: *"Every card shows data freshness. The agent never hides what it doesn't know."*
- **Don't leave the cursor wandering.** Park it off-screen between clicks.

---

## Cuts to make if you're running long

In order:

1. **Drop Fort Stockton entirely.** Wimberley + Taylor cover personal + transparency, and Taylor carries the hero artifact.
2. **Trim Wimberley to 30 seconds** — skip the Drought card narration.
3. **Trim Taylor to 60 seconds** — skip the "review before sending" beat (it's visible on screen).

Never cut: the cross-reference tension beat in Taylor, the public-comment artifact, or the Comanche Springs flatline if you're keeping Fort Stockton at all.
